# Contributing

## Development

```bash
npm ci
npm run typecheck
npm test
npm run build
```

Keep changes scoped, add tests for behavior changes, and never commit credentials or real synchronized user data. Network features must be documented in `PRIVACY.md`, use HTTPS, and preserve the default-deny private-network policy.

## Pull requests

Describe the user-visible behavior, security or privacy impact, and validation performed. By contributing, you agree that your contribution is licensed under the MIT License.
